포트폴리오 사이트 사용설명서
====================================

■ 확인하는 법
  index.html 을 더블클릭하면 브라우저에서 바로 열립니다.
  파일을 고치고 저장한 뒤, 브라우저에서 새로고침(Cmd+R / Ctrl+R)하면 바뀐 모습이 보입니다.


■ 폴더 구조 (이것만 알면 됩니다)

  Portfolio/
  ├─ index.html          뼈대 ........................ 건드리지 않아도 됩니다
  ├─ css/style.css       디자인(색·글자 크기) ........ 건드리지 않아도 됩니다
  ├─ js/app.js           동작 ........................ 건드리지 마세요
  ├─ fonts/              글꼴 파일 ................... 건드리지 마세요
  │
  ├─ content/            ★ 글을 고치는 곳 ★
  │   ├─ site.js           이름, 이메일, 맨 위 큰 이미지
  │   ├─ about.js          About 페이지 (소개 글 + 사진)
  │   ├─ career.js         Career 페이지 (기간·제목·설명 줄)
  │   ├─ branding.js       Branding 작업물 목록
  │   ├─ product.js        Product 작업물 목록
  │   └─ campaign.js       Campaign 작업물 목록
  │
  └─ images/             ★ 사진·영상을 넣는 곳 ★
      ├─ branding-01/       작업마다 폴더 하나
      │   ├─ thumb.jpg        썸네일
      │   ├─ 1.jpg            상세 이미지 (위에서부터 차례로)
      │   ├─ 2.jpg
      │   └─ 3.jpg
      ├─ branding-02/ ...
      ├─ about/             About 페이지 사진 (1.jpg. 바꾸려면 about.js 의 images 에 파일 이름을 적기)
      ├─ hero.jpg          맨 위 큰 이미지 (PC) - 지금은 제가 만든 기본 이미지입니다. 같은 이름으로 바꿔 넣으면 됩니다
      └─ hero-mobile.jpg   맨 위 큰 이미지 (모바일)


■ 이런 걸 바꾸고 싶을 때

  이름 / 이메일 ........................ content/site.js
  About 소개 글 ........................... content/about.js
  Career 경력 줄 ......................... content/career.js ({ } 한 덩어리 = 한 줄)
  맨 위 큰 영상·이미지 바꾸기 ............ content/site.js 의 hero 부분 + images 폴더에 파일 넣기
  작업 제목, 연도, 설명, 기간 ............ content/ 안의 해당 섹션 파일 (branding.js 등)
  작업 이미지 바꾸기 ..................... images/작업폴더/ 안의 파일을 같은 이름으로 덮어쓰기
  작업 추가하기 .......................... 해당 섹션 파일에서 { } 한 덩어리 복사 → 붙여넣기 → 내용 수정
                                           + images 에 같은 이름의 폴더 만들기
  작업 순서 바꾸기 ....................... { } 덩어리를 통째로 위아래로 옮기기
  작업 지우기 ............................ { } 덩어리를 통째로 지우기 (앞 덩어리 끝 쉼표 확인)


■ 이미지 크기 (이 크기로 만들면 깨지지 않습니다)

  위치                 파일 이름 예시          크기
  ------------------------------------------------------------------
  맨 위 큰 이미지(PC)   hero.jpg / .gif         2400 x 1050 px
  맨 위 큰 영상(PC)     hero.mp4                1920 x 840 px
  맨 위 큰 이미지(모바일) hero-mobile.jpg / .gif 1200 x 1500 px
  맨 위 큰 영상(모바일)  hero-mobile.mp4         1080 x 1350 px
  썸네일               thumb.jpg               1600 x 900 px (16:9)
  상세 이미지          1.jpg, 2.jpg ...        가로 1600 px, 세로는 자유

  * JPG / PNG / WebP 가능. 한 장에 1MB 이하를 권장합니다. (사이트가 빨라집니다)
  * 영상은 mp4 형식, 10MB 이하. GIF는 5MB 이하. (GIF보다 mp4가 훨씬 가볍습니다)
  * 썸네일이 16:9가 아니면 가운데를 기준으로 잘려 보입니다.
  * 파일 이름은 영문 소문자·숫자·-·_ 만 쓰세요. 한글이나 띄어쓰기는 쓰지 마세요.
  * .jpg 와 .jpeg, .png 처럼 확장자도 코드에 적은 것과 똑같아야 합니다.
    (png 를 쓰고 싶으면 content 파일에서 thumb: "branding-01/thumb.png" 처럼 같이 바꾸세요.)


■ 글을 고칠 때 이것만 조심하세요  (코드 편집기에서 수정할 때)

  1. 따옴표 " " 는 지우지 마세요. 글자는 따옴표 안에만 쓰세요.
  2. 줄 끝의 쉼표(,)를 지우지 마세요.
     단, 마지막 항목 뒤에는 쉼표가 없어도 됩니다.
  3. 글 안에 따옴표를 쓰고 싶으면 " 대신 ' 를 쓰세요.
  4. 줄바꿈은 \n 이라고 쓰세요.
  5. 이상해지면 Cmd+Z (되돌리기)로 바로 되돌리세요.
  6. 작업물 파일(branding.js 등) 하나에 실수가 있어도 다른 섹션은 정상으로 보입니다.
     어느 섹션이 비어 보이면 그 섹션의 파일을 확인하세요.


■ 인터넷에 올릴 때

  Portfolio 폴더 안의 파일 전체(사용설명서.txt 제외해도 됩니다)를 그대로 올리면 됩니다.
  자세한 방법은 작업이 끝난 뒤 같이 진행해요.


[맨 위 검정 소개 영역]
content/site.js 의 intro 에서 큰 제목(title), 문단(paragraphs), 둥근 버튼(steps)을 바꿀 수 있습니다. title 을 비우면 이 영역이 사라집니다.


■ 상세 페이지 글·이미지 쓰는 법 (content/ 안의 branding.js, product.js, campaign.js)
  sections 안의 { } 하나가 상세 페이지의 한 줄입니다. (PC: 왼쪽 큰 이미지 / 오른쪽 글, 모바일: 큰 이미지 → 글)
    images : 그 줄의 이미지들 (옆으로 넘기면 차례로 보임, 2장 이상이면 화살표가 나옴)
    desc   : 그 줄 오른쪽에 보일 글. 줄을 바꾸려면 \n, 소제목은 줄 맨 앞에 ##, 굵게는 **이렇게**, 형광펜은 ==이렇게==
  예)  desc: "## 행사 부스\n행사의 목적과 방문객 동선을 분석했습니다. ..."


[Role / Scope / Output 표 넣기]
  content 파일의 작업 덩어리에 facts 줄이 있으면, 제목·태그 아래에 표로 나옵니다.
    facts: [
      ["ROLE",   "맡은 역할 한 줄"],
      ["SCOPE",  ["항목1", "항목2"]],
      ["OUTPUT", ["결과물1", "결과물2"]]
    ],
  기여도(contrib)는 맨 아래 줄 "기여도 90%" 에만 나옵니다. (ROLE 줄에는 붙지 않습니다)
  연도(year)는 상세 페이지 제목 바로 아래에 나옵니다. 메인 썸네일 아래에는 연도가 나오지 않습니다.
  링크(link)를 적으면 Role/Scope/Output 표 맨 아래에 "LINK  사이트 바로가기 ↗" 줄이 생깁니다. (비우면 줄이 없습니다)

■ 글 편집기 (코드 없이 글을 고치는 화면 · 내 컴퓨터에서만 씁니다)
  1) 폴더의 「관리자」 안 「편집기.html」 을 크롬(Chrome)으로 엽니다. (더블클릭 후 크롬 선택)
  2) 위쪽 「폴더 연결」 → Portfolio 폴더를 고릅니다. (허용 물음이 나오면 허용)
  3) 왼쪽에서 작업을 고르고, 제목·연도·부제목·칩·기여도·Role/Scope/Output·상세 글을 고칩니다.
     맨 아래 「About me」에서는 소개 글과 사진을 고칩니다. (굵은 글씨는 __이렇게__ 감싸기)
     이력서(PDF)는 Portfolio 폴더 맨 바깥에 resume.pdf 로 두면 About 이름 아래에 "Resume (PDF) ↗" 로 나옵니다. (파일 이름을 바꾸면 content/about.js 의 resume 도 같이 바꾸기)
     ※ 이력서 PDF 는 공개되므로 전화번호·주소·금액은 가린 파일만 넣으세요.
     기여도가 부분마다 다를 때만 「부분별 기여도·연도」 칸에 한 줄에 하나씩 적습니다.
     이미지는 줄마다 「+ 이미지 추가」, 순서는 ← →, 줄 순서는 ↑ ↓ 로 바꿉니다.
  작업 추가·삭제: 왼쪽 목록 아래 「+ 작업 추가」로 새 작업을 만들고, 작업 화면 위쪽의 「작업 ↑ ↓」로 순서를, 「이 작업 삭제」로 목록에서 뺍니다. (이미지 파일은 남습니다)
  4) 「저장」을 누르면 파일에 반영됩니다. (저장 전 파일은 _backup/편집기-저장전 에 남습니다)
  5) 사이트에 올리려면 Claude에게 "갱신"이라고 말하세요. 저장만으로는 공개되지 않습니다.
  ※ 「관리자」 폴더는 인터넷에 올라가지 않습니다.
